# Docs Guide

Use the runtime code and architecture governance docs as the source of truth for implemented behavior.

## Canonical / Actionable

These are the primary docs to consult when reasoning about the current system:

- `architecture-contract.yaml`
- `architecture-contract-audit.md`
- `architecture-tracks.md`
- `architecture-continuity-layer.md`
- `statelock-cognitive-architecture.md`
- `architecture-memory-*.md`
- operator and local-stack docs

## Session Context Only

Files under `session_context/` are for rehydration and handoff.

They are useful for prior-session awareness, but they are not authoritative architecture guidance.

## Brainstorming / Review

Files under `brainstorming/` are exploratory.

Treat them as ideation, review notes, or candidate future direction unless their conclusions are promoted into the canonical docs above.
