WHAT IS STATELOCK

StateLock helps AI systems remember the right things during long conversations and ignore stale or off-topic details.

WHAT PROBLEM IT SOLVES

Long chats can drift. Useful facts get buried and topics mix together. StateLock reduces context drift and topic mixing by tracking topic threads and scoring context influence.

HOW IT WORKS

turn -> span -> thread -> working context -> telemetry

  1. A turn is added.
  2. Segmentation splits turns into spans.
  3. Spans are assigned to threads (topics).
  4. A working context is assembled for the next answer.
  5. Telemetry measures which spans influenced the model response.

QUICK START

  1. Create conversation
  2. Add turns
  3. Run segmentation
  4. Build working context
  5. Run telemetry
curl -s -X POST http://127.0.0.1:8000/v2/conversations \
  -H "Authorization: Bearer dev-key" -H "content-type: application/json" \
  -d '{"title":"demo"}'

curl -s -X POST http://127.0.0.1:8000/v2/conversations/<CID>/turns \
  -H "Authorization: Bearer dev-key" -H "content-type: application/json" \
  -d '{"speaker":"user","text":"Help me debug packet loss"}'

curl -s -X POST http://127.0.0.1:8000/v2/conversations/<CID>/segment \
  -H "Authorization: Bearer dev-key" -H "content-type: application/json" \
  -d '{"mode":"incremental"}'

curl -s -X POST http://127.0.0.1:8000/v2/conversations/<CID>/working_context \
  -H "Authorization: Bearer dev-key" -H "content-type: application/json" \
  -d '{"query":"packet loss troubleshooting"}'

curl -s -X POST http://127.0.0.1:8000/v2/conversations/<CID>/telemetry \
  -H "Authorization: Bearer dev-key" -H "content-type: application/json" \
  -d '{"turn_id":"<TID>","query":"packet loss troubleshooting","mode":"verbose"}'

KEY CONCEPTS

  • turn: one user/assistant/tool message.
  • span: a chunk of text derived from turns.
  • thread: a topical cluster of spans.
  • working context: selected text sent to the model for the next response.

TELEMETRY EXPLANATION

Proxy influence is a fast estimate of how much each span matters. Ablation is measured influence: remove one span and measure output KL change.

METRICS EXPLANATION

  • entropy (H): how spread influence is across spans. Higher means more diffuse context use.
  • off-thread coupling (Coff): influence mass outside the target thread. Higher means more off-topic coupling.

ALARM EXPLANATIONS

  • anchor rot: stale or off-thread anchor span dominates influence.
  • smear rot: influence is overly spread across many spans.
  • off-thread spike: off-thread coupling jumps compared to previous state.
